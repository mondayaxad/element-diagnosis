## 判定式の実装と、指示書の数値との差（要確認）

式は指示書 §3 のとおり（50:50 の配合、元素・武器は正規化 RMSE 最小、国家は結合後に中心化したコサイン最大、同点は代表表の挿入順で先）。

**同点の扱いだけ、浮動小数点では規則を守れない**ため、整数で厳密に比較している。
- 代表座標・キャラ座標はすべて整数なので、50:50 の結合後の座標は半整数になる。2つの代表への距離が**数学的に完全に同じ**になる組み合わせが多い（1位の同点：元素 1,840・武器 336・国家 0 / 33,040 通り）。
- 浮動小数点で計算すると、計算の順序による誤差で同点の勝ち負けが入れ替わり、「挿入順で先」にならない。
- 例：炎・片手剣・モンド × ディルック。結合後の PERSONALITY は (45, 80, 60, 57.5, 55)。炎・水への二乗和はどちらも 1206.25（同点）なので、規則上は**炎**（golden の期待値）。本家の `rankByDistance` は誤差で**水**を返す。

| 実装 | いずれかが変化 | 0/1/2/3 属性の変化 | golden |
|---|---|---|---|
| **今回の実装（厳密比較）** | **42.682%** | 18,938 / 11,722 / 2,245 / 135 | **8/8** |
| 同梱の参照 JS | 42.633% | （今回の実装と 136 通りで違う。すべて同点の箇所） | 8/8 |
| 本家 `ETIv2.rankByDistance` 等をそのまま使う | 43.130% | （今回の実装と 496 通りで違う。すべて同点の箇所） | 7/8 |
| 指示書 §4 の記載 | 42.887% | 18,870 / 11,747 / 2,287 / 136 | — |

- 指示書の 42.887% は、同梱の参照 JS でも再現できなかった（別の計算環境の値と推定）。
- 試験では、33,040 通りすべてについて、浮動小数点で独立に距離を計算し「最小値から 1e-12 以内を同点として挿入順で先」の規則と一致することを確認。参照 JS・本家の関数と違うのは、**1位が同点の箇所だけ**であることも確認した。
- 280/280 の回答で、選ぶキャラによって結果が変わり得る（指示書と同じ）。
- **回帰の基準は 42.682%（今回の実装）として試験に固定した。** 指示書の 42.887% を正とする場合は、同点の扱いの規則を ChatGPT が改めて決める必要がある。
