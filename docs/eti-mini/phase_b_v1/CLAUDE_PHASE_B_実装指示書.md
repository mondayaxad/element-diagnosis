## 3. キャラ手動選択時の確定数式
選択対象は登録118名すべて。選択キャラ自身を結果欄に表示する（別キャラへの再選出をしない）。

PERSONALITY / STYLE / VALUES 各軸について、回答した属性のETI v2代表座標と選択キャラのETI-CHAR-2.1.0座標を等配合する。

`merged[axis] = 0.50 * prototype[answer][axis] + 0.50 * character[axis]`

- 元素（5軸）・武器（5軸）は本家の **正規化RMSE最小**を選ぶ。
- 国家（10軸）は本家の **平均中心化コサイン類似度最大**を選ぶ。中心化は結合後の各ベクトルに対して実施する。
- 同距離は各プロトタイプ辞書の元の挿入順を優先（配列の並べ替え・名前順ソートは禁止）。
- スコアの四捨五入、座標の途中での丸め、元キャラのゲーム内属性への寄せ、元素・武器・国家の強制一致は禁止。
- 空キー・不正キャラ・欠損軸では結果を表示せずエラー。既存の旧版 `CHARACTERS` から座標を取得しない。
- キャラ選択後のETIタイプ名とコードは**再判定後の**元素・武器・国家で本家辞書から取得する。選択したキャラの元素・国家をそのまま表示しない。
- **内部判定バージョン `ETI-MINI-MANUAL-1.0.0`・重み `0.50` を固定**し、将来のレポート購入スナップショットではこれらと選択キャラ名・最終結果を保存する（Phase C作業）。
- 参考実装 `eti_mini_manual_engine_reference.js` は純粋関数。既存本家 `ETIv2` の関数を再利用してもよいが、その場合は同じ順位と結果になることをテストする。

## 4. 全件検証（今回の実座標に基づく）
- 280回答×118名＝**33,040入力ペア**を算出。
- 回答からの変化なし：**18,870**件。1属性変化：**11,747**件。2属性変化：**2,287**件。3属性変化：**136**件。
- いずれかが変化：**42.887%**。
- **280/280回答**で、手動選択キャラを変えると結果が異なりうることを確認。
- λ=0.40→13.511%、0.45→24.401%、0.50→42.887%、0.55→60.705%。今回は中立な50:50を確定値とする。
- 数値は**本家の心理尺度の妥当性を証明するものではない**。Miniの固定ルールの結果分布。ユーザー画面に数値スコアは出さない。
- 以前の暫定集計で示した42.63%とはわずかな差があるため、**今回の添付実座標・添付参照実装で再検証した42.887%をPhase B回帰基準**とする（元の本家JSの厳密浮動小数点挙動との差はClaude側で検証し、差があれば行単位で報告）。
