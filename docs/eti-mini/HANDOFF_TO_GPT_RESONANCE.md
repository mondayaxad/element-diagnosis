## 1. いまの仕様（Character Reveal Edition・確定分）

### 流れ
表紙 → 3問 → 登場演出 → 無料結果 → ¥500 人物像レポートの見本（非販売）→ 購入ボタン（準備中・押せない）→ Xでシェア → 100問の元素診断への案内

### 3問
- 元素 7択・武器種 5択・国家 8択。選択肢は見出しと説明だけで、元素・武器種・国家の名前は出さない
- 並びは固定の混ぜ順（来訪ごとに変えない）
  - 元素：岩・雷・水・草・炎・氷・風
  - 武器種：長柄・法器・片手剣・弓・両手剣
  - 国家：スメール・ナタ・璃月・ナドクライ・フォンテーヌ・モンド・スネージナヤ・稲妻
- 3つの答えで「758」（元素×武器種×国家＝280タイプ）が決まる

### 現れる人物
- 280タイプそれぞれに1名の固定割当（★5の66名を4〜5回ずつ）。同じ3回答なら必ず同じ人物。乱数・再抽選なし
- 表記は「アナタに共鳴する人物は――〔人物名〕」。「最も近しい」「類似度1位」とは書かない
- 一致率・心理スコアなどの数値は出さない
- 人物を選ぶ工程・2人比較・画像保存・タイプ解説ページへのリンクは無し

### 完了画面（結果ページ）
1. 星座の円（本家 OGP の正式背景の円の部分）＋「アナタに共鳴する人物は――」＋人物名
2. 「元素 × 武器種 × 国家」、タイプ名「深識者」、コード「HYCT-F」
3. 一文：「〔元素の言葉〕」という気質を持ちながら、「〔武器種の言葉〕」というかたちで人と関わり、「〔国家の言葉〕」を大切にする人。（黄色の言葉は本家 index.html と同じ）
4. ¥500 人物像レポートの見本 → 購入ボタン（準備中） → Xでシェア → 100問の元素診断へ → 最初から答え直す

- 登場演出：星の光 → 円 → 光の広がり → 「アナタに共鳴する人物は――」 → 名前 → 758・タイプ名（約2.8秒、タップで省略）。動きを減らす設定・シェアリンク・戻る/進むでは演出しない
- **色のルール：星座・夜空の灯り・人物名のグラデーションは、現れた人物（キャラ）の元素の色**（完了画面もシェアから開いたページも同じ）

### ¥500 人物像レポートの見本（非販売）
- 商品名：共鳴診断｜人物像レポート／税込500円・買い切り（本家の商品とは別管理）
- 注記：「見本の表示です。図の形は実際のレポートとは異なります（購入後に、アナタの結果で描かれます）。」
- 6項目。軸・項目名は見せ、図の中身はぼかして「LOCKED ・ 購入後に表示」
- **図は全員同じ固定のダミー（形も色も固定：アナタ＝青、人物＝金）**。結果ごとに変わるのは PERSONA の人物名だけ

| 項目 | 見出し | 図 | 軸・項目 |
|---|---|---|---|
| PERSONA | アナタ × 〔人物名〕　性格の重なり | レーダー | 開放性・誠実性・外向性・協調性・感受性 |
| STYLE | 行動の傾向の比較 | 横棒（2人並び） | 主導性・関係調整・役割持続・媒介思考・自律距離 |
| VALUES | 価値観の地図 | 円形の配置 | 自分で選ぶ・新しい刺激・楽しみ・達成・影響力・安定・節度・伝統・思いやり・公正さ |
| SYMBOLS | 元素・武器種・国家の象徴 | 元素7本の横棒 | 代表座標から見た、ほかの元素との「象徴的な近さ」（心の測定値ではない） |
| RESONANCE | 共鳴する人物との共通点・相違点 | 文章（ぼかし） | 共通点・相違点 |
| JOURNEY | 自己理解の問い | 文章（ぼかし） | アナタへの問い |

### Xシェア
- 投稿文：「共鳴診断をやってみました。／私に共鳴する人物は――「〔人物名〕」／【元素 × 武器種 × 国家】「タイプ名」／URL／#共鳴診断 #元素診断 #〔人物名〕」
- URL：`/api/share?m3=〈符号〉` → クローラーには OGP 画像、人は `/resonance?c=〈符号〉` へ
- 符号 m3（版 RESONANCE-SHARE-3）：タイプ280 × 人物118 = 33,040通り、36進で最大3文字。人物は値として持つ（割当表が変わっても過去のリンクの表示は変わらない）
- 旧リンク m1（`?s=`）・m2（`?r=`）も表示できる（互換）

### OGP 画像（Xに投稿したときの画像、1200×630）
- 人物が主役のレイアウト。背景の星座の円環・人物名のグラデーション・名前の後ろの光・枠は**人物の元素の色**。元素のタグだけ本人の元素の色
- 描く情報：見出し「共鳴診断 — MY RESULT」、YOUR RESONANCE と人物名（いちばん大きく）、YOUR TYPE とタイプコード4文字（例 HYCT）・タイプ名、元素／武器種／国家のタグ
- 下帯の文は描かない。一致率は描かない
- タイプコードは本家の画像と同じ4文字（画像用フォントに「-」が無いため。国家はタグで示す）
- 下地は人物の元素ごとの7枚（`assets/ogp/bases-reveal/`）。本家・旧 m1・m2 の画像は変更なし

## 3. ChatGPT にお願いしたいこと（未確定）

1. **人物像レポート（¥500）の本文テンプレートと文章生成規則**（PERSONA／STYLE／VALUES／SYMBOLS／RESONANCE／JOURNEY の6項目）
2. **各図の計算式**
   - PERSONA：アナタ側の5軸の値を3回答（758）からどう出すか（人物側はデータあり）
   - STYLE：同上（5軸）
   - VALUES：同上（10価値観）。「共鳴する／すれ違う」の判定基準
   - SYMBOLS：「代表座標から見た、ほかの元素との象徴的な近さ」の定義
   - 心理スコア・一致率として見せない表現の範囲
3. 購入後の保存（スナップショット）・再閲覧・DB・決済の仕様、法務ページ（特商法・利用規約）への価格の記載

### 使えるデータ（人物側）
`js/characters118_v2_1.js`（ETI-CHAR-2.1.0、118名）の各人物に次の値がある（0〜100）。例：ティナリ

```
element 草 / weapon 弓 / region スメール
personality（Big5）: O 70, C 80, E 45, A 55, N 45
style: AGY 60（主導性）, REL 70（関係調整）, ROL 80（役割持続）, REF 75（媒介思考）, AUT 55（自律距離）
values（Schwartz 10）: SD 65, ST 55, HE 50, AC 70, PO 50, SE 60, CO 70, TR 55, BE 65, UN 75
basis_tags: 知的探究・指導・役割責任・実利・共感・規律
```

- 元素・武器種・国家の代表座標（プロトタイプ）は `js/eti_v2_prototypes.js`
- 280の固定割当表は `js/eti_mini_auto_map_v1.js`（出典 `docs/eti-mini/handoff_v1/data/`、sha256 で固定）
- 購入時に保存する案：3回答（内部キー）、758・タイプ名、人物、各データの版（core・割当表の版と sha256・本文テンプレートの版）、価格500・商品ID、注文ID、作成日時。再表示で再計算しない。メール・決済情報は持たない
