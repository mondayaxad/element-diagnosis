# 改稿例｜旧辞書と新辞書の比較

登録座標と公式設定を混ぜて同一視しない構成に変更しました。

## フリーナ

**旧：登録モデル**
この登録モデルでは、新しい見方への関心と周囲との調整が目立ちます。価値観では「身近な人への思いやり」の相対的な優先度が高く、人物像の根拠タグには「表現、社交」が含まれています。

**新：登録モデル**
人々の注目を集めるフォンテーヌの人物として、公開裁判という舞台と観客の視線に関わってきた。見せる表現と、個人としての受け止め方を混同しない視点が大切になる。登録モデルでは、新しい見方への関心と周囲との調整が目立ち、価値観の中では「身近な人への思いやり」が相対的に前に出る設定です。

**旧：共鳴解釈**
フリーナの登録モデルに表れた「身近な人への思いやり」への向き方と、回答から描いた人物像を並べてみると、似た言葉でも大切にする理由は違うかもしれません。周囲との調整という特徴が、自分の選択にどの程度重なるかを問い直すことが、この共鳴を楽しむ一つの方法です。

**新：共鳴解釈**
人に見られる自分と、ひとりで感じる自分が、いつも同じとは限りません。フリーナとの共鳴を考えるなら、周囲の期待に応える表現と、自分が本当に大切にするものの違いに目を向けてみてください。
