## 文章生成側の既知の確認点

- `composeText` の PERSONA：`comboInteraction` は句点あり、`nationLens` が続く構成。本辞書で280件の字面接続は確認済み。
- JOURNEY：旧辞書には末尾「？」とテンプレートが付ける「。」の **`？。`** があった。今回の `journeyCombo` 40項目は末尾の句読点を入れず、現行テンプレートが「。」を足しても自然な文章にした。
- RESONANCE：`characterReading` は軸を固定で名指ししない。具体的な一致軸・相違軸は計算結果の文章を必ず併記する。
- VALUES：図と本文の平均中心化比較を維持する。誤って0〜100の実測性格スコアとして見せない。
- SYMBOLS：象徴的な近さを個々の元素の心理測定スコアと言い換えない。
