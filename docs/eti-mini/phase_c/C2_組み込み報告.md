## 4. 66名の確認（指示書 4〜6）

- **名前**：66名のキーは登録データ（ETI-CHAR-2.1.0）の表記と完全一致。ほかのキャラ名を含む文は2件（イネファ→アイノ、スカーク→タルタリヤ）。いずれも人物紹介としての言及
- **地域**：千織＝稲妻出身・フォンテーヌを活動拠点（指示どおり）／スカーク・ニコ＝国家の所属を書いていない／タルタリヤ＝スネージナヤ出身／サンドローネ・アルレッキーノ＝国家を明記していない（アルレッキーノは壁炉の家に言及）／オデット＝喪失・家族・シニョーラとの関係は書いていない
- **測定との区別**：RESONANCE ①に「アナタを測定したものではありません」、SYMBOLS に「個々の心理特性を測定した結果ではありません」、レポート冒頭に共通の注記。登録モデルの説明は「登録モデルでは…」で始まる

## 5. ChatGPT に直してほしい点（辞書側。Claude は辞書の文を変えていない）

1. **「あなた」表記が3件**（サイトの表記は「アナタ」）：characterReading の ウェンティ・八重神子・閑雲
2. **価値観の言い方が図の項目名と違う**：characterModel の「自分で選ぶこと」（図は「自分で選ぶ」）、「変化と刺激」（図は「新しい刺激」）、「身近な人への思いやり」（図は「思いやり」）。読者が図と本文を見比べると別の項目に見える。どちらかにそろえたい（図・本文の項目名は無料の見本・`resonance.html` とも共通）
3. **SYMBOLS 章で否定の文が続く**：symbolMeaning の末尾「…個々の心理特性を測定した結果ではありません」の直後に、テンプレートの「下の元素図は…距離を示したものです。ほかの元素を個別に測定した結果ではありません」が来る。symbolMeaning から注記を外すか、テンプレート側の最後の文を外すか、どちらかを決めてほしい
4. **domainScene.values が「共通する性質」の中で違いを述べる**：「何かを選び、何かを諦める場面では、同じ価値を大切にしていても理由は異なることがあります」。共通点の区分なので、重なりが現れる場面の書き方が合う
5. **characterModel の末尾「…が相対的に前に出る設定です」**：「設定」が公式設定の意味に読まれるおそれ（指示書 4 の「設定を性格の実測値と誤認させる文」に近い）。「…登録モデルの特徴です」などが無難
6. **ゲーム内での再照合が要る記述**（Claude はゲーム内テキストを確認できない）：ローエン「西風騎士団の第5小隊副隊長」、オデット「ファデュイの任務も担う」、スカーク「タルタリヤに武芸を教えた師」、イネファ「アイノと暮らすロボット」、ニコ「魔女会に属し、世界線の観測者」など、裏付けレベル B の記述
