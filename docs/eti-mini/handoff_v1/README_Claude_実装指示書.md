## 1. 確定した商品仕様
- 元素診断 Mini：3問、各1択。元素7・武器種5・国家8（7×5×8=280）。選択肢の見出し＋一文解説。元素・国家・武器の名前を質問中には直接明示せず、順序を混ぜる。回答は位置番号でなく内部キーで保存する。順序をランダム化するならセッション中は固定。
- 結果：元素、武器種、国家、既存35タイプ名・コード、近しいキャラ、簡潔な言葉・信念。**点数・一致率・疑似Big Five値は表示しない。**
- 任意のキャラ手動選択：本家MIRRORの登録118名全員から検索可能。選択ありの場合は回答の3代表座標と選択キャラのPERSONALITY/STYLE/VALUES座標でETI結果を再判定（※具体的な結合式はChatGPTが別途確定する。現段階で推測・実装禁止）。選択したキャラはユーザー指定として明示する。
- 未選択：本パッケージの280固定表から1キャラを表示する。候補は対象66名に限定。
- レポート商品：**専用「人物像レポート」税込1,000円の一種類のみ**。本家の解析・完全解析とは別商品。スコア表示なし。固定解説は心理尺度の測定値であるかのように扱わない。
- Miniはマイページ連携なし。購入結果は購入時のスナップショットを固定保存し、再閲覧できる導線を用意する。未購入者の結果にも共有導線を検討。ただし認証・購入権限の検証・推測不能な再閲覧URLは必須。
- 最下部に本家100問の元素診断へ誘導：「元素診断で、もっと深く自分を知る」。100問・基本無料を案内する。Miniの有料商品の案内より下に配置。

## 2. 自動排出の正式読み取り仕様（実装対象）
`data/eti_mini_758_5star_280_mapping.json` を変更せず、`rows[].key` を `元素|武器|国家内部キー` に一致させて参照する。
- 国家内部キーは `ナドクライ`、画面表記は **ナド・クライ**。
- `mirror_character` が固定結果。リロードや購入時に再抽選しない。
- `internal_rank`、`internal_regret_pp` は監査専用。画面・レポート・Xシェアで公開しない。
- 3問未回答時や辞書にないキーでは結果を出さず、明示的なエラーとする。
- 結果のETI（元素・武器・国家）と、表示キャラクターのゲーム内属性は一致する必要がない。勝手にキャラクター属性へ寄せない。
- `data/eti_mini_auto_candidates_v1.json` の候補66名と `characters_full.json` の118名を照合する。Miniの自動候補の変更は禁止。

## 3. 自動排出表の再監査結果
- 入力：280/280のキーが存在、重複なし。7元素・5武器・8国家の直積を完全網羅。
- 対象：66名全員出現。50名が4回、16名が5回。候補外0、座標DBとの不一致0。
- 類似順位：5位以内227/280、10位以内270/280、11位以下10/280。最悪27位。
- 内部類似度の逸失：平均1.2189ポイント、最大6.5148ポイント。5ポイント超は9/280。
- **解釈**：回答280通りが均等に選ばれた場合の「パターン数」が均等。実利用者のキャラ表示比率が均等になる保証はない。最悪27位の例外があるため、心理的近似性を厳格に要求するなら再最適化が必要。均等化優先の候補として採用し、公開前に利用者の判断を受ける。
- 最大逸失例：炎|両手剣|ナドクライ→胡桃（27位）。絶対的な適合率と解釈しない。

## 5. 未確定事項（Claude側で独自決定禁止）
1. **キャラ手動選択ありの重みと結合数式**（以前の50:50は仮説であり確定していない）。専用モジュールのインターフェースを先に用意し、計算実体はChatGPTからの追補指示後に接続。
2. **Mini用の7・5・8選択肢の最終日本語文**：既出叩き台は仮案。本家定義に合わせて確定後に反映。属性名称の直接露出を避ける。
3. **1,000円レポート本文と構成**：心理測定スコアを捏造しない。ChatGPTの文章規則が確定するまで仮コンテンツを販売しない。
4. **本番決済・再閲覧手段**：本家の既存購入と混線させず、別の商品・権利・保存を設計。購入時はタイプ・キャラ・文面のバージョンを含むスナップショットを保持し、再表示で再計算しない。
5. **66名のレアリティ・Ver.7.0の出典**：本パッケージに既存候補表を同梱しているが、公式一次資料による全員分の裏取りログがここに含まれているわけではない。公開前に再点検。
