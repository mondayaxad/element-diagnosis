# ETI v2 キャラクター座標・偏り調整報告

作成日: 2026-09-28\
対象: 118キャラクター / PERSONALITY 5軸・STYLE 5軸・VALUES 10軸\
更新案: `ETI-CHAR-2.0.1` / `ETI-MIRROR-2.0.2`

## 結論

118名を監査し、設定根拠と合成分布の双方から再評価が必要だった12名だけを調整した。残る106名は、分布だけを均す目的では動かしていない。

固定seedの合成入力2万件では、最大top1率は8.335%から5.135%、top5集中率は31.200%から18.615%、top10集中率は44.685%から31.575%へ低下した。top1が0件のキャラクターも9名から6名へ減った。

ただし、この試験は実ユーザーの排出率ではない。各20軸を独立な正規分布 `N(50,15)` から生成した、座標の重なり・中心集中を検出するための合成診断である。118名を一律0.847%へ近づけることは目的にしていない。

## 調整方針

1. ゲーム内プロフィール・物語・ボイスの記述を優先する。
2. wikiwikiの考察・性能欄は性格根拠に使わない。
3. 「言及がない」ことだけを理由に価値観を極端化しない。
4. 出現率を下げるためだけの軸移動はしない。
5. 設定上の個性が示す方向と、20軸の設問定義が対応する場合だけ値を動かす。

このため、ドリーの権力・達成・安全志向、タルタリヤの刺激・達成・権力志向は低くせず、むしろ物語に合う方向へ明確化した。早柚は怠惰さだけに寄せず、終末番への忠誠、訓練された技能、自律性、見捨てられ不安を同時に反映した。

## 注意点

合成入力の独立正規分布は、実際の回答者の軸間相関や回答尺度の癖を表さない。リリース後は匿名化された実回答について、top1率だけでなく、軸分布、top4、距離差、再診断の安定性を確認すべきである。実利用データが得られるまでは、これを「排出率」ではなく「座標占有率のストレステスト」と呼ぶのが正確である。
