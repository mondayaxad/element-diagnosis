# ファトゥス判定の整合性レビュー（現行：人物判定 0.8.0／2026-11-10）

この文書の冒頭は**現行の仕様**です。0.4.0〜0.7.0 の経緯と、採用しなかった案（案C・±5の補正上限・5ポイントの下限）は、末尾の「履歴」にまとめています。

## 1. 現行の仕様（0.8.0）

### 1.1 オーナーの要件
- 50問の回答から順位を出し、11名が均等に現れること。
- その順位を、レポート・結果ページ・Xシェアの OGP（1位＝あなたのファトゥスと一致度）に反映すること。
- 1位より2位の一致度が高い、という矛盾を出さないこと。
- 読者向けの表示（PDF・Web レポート・結果ページ・マイページ・共有・OGP）には、重み・補正値などの計算説明を出さないこと。計算仕様はこの文書と spec 一式に残す。

### 1.2 計算
- **近さ（similarity）**＝ 0.75 ×（照合する特性での、本人の得点と人物の参照の近さ。RMSE から算出）＋ 0.25 × 100 ×（目立つ特性の割合）
- **目立つ特性の割合**＝（照合する特性の中の目立ち ＋ 20 × 0.5）÷（全特性の目立ち ＋ 20）。目立ちは50点を超えた分です。0.7.0 から、境界で急変しない式にしています。
- **順位に使う値**＝ 近さ ＋ 人物ごとの固定の補正（selection_offset）。
- **表示する一致度**＝ 順位に使う値を 0〜100 に収めて四捨五入した値（0.6.0〜）。順位と同じ値なので、上の順位ほど一致度が高くなります。同じ％が並ぶことはあります。
- **同点**：回答から決まる固定の順序で1位を決め、1位を一覧の先頭に置きます。
- **本文の「近い／やや近い／離れている」**は、補正を含まない、照合した特性ごとの差で書きます（15以内・16〜25・26以上）。

# 履歴（0.4.0〜0.7.0。現行ではない仕様を含みます）

以下は当時の記録です。案C（5ポイントの下限）、±5の補正上限、補正前の％の表示は、いずれも現行では使っていません。

オーナー指示（2026-11-08）：均等排出は維持する。判定結果・一致度・本人の得点・人物説明の矛盾を解消する。

### 1. 不整合が生じていた箇所（0.4.0 時点で特定）

| 値 | どこで使っていたか | 中身 |
|---|---|---|
| 順位に使う値 | `judge.mjs` characterRanking の並び（selectionScore） | 近さ（similarity）＋人物ごとの固定補正（selection_offset） |
| 表示する一致度 | `character.match`・一覧の％（displayScore） | 近さ（similarity）を丸めた値。補正は足さない |
| 本文の「近い／違う」 | `explainCharacter`（差15以内＝近い、20以上＝違う） | 比較に使う特性だけの、本人の得点と参照値の差 |

- **06 TOP11 の一覧**は補正後の順で並べ、補正前の％を表示していました。そのため、一覧の％が上下に入れ替わる回答が 93〜98% ありました。説明なく混在していた状態です。
- **補正による入れ替わり**：均等化のため、最も近い人物とは別の人物を選ぶ回答が約22%ありました。そのときの近さの差は、最大 7.6〜8.9 ポイントでした。
- **一致度の中身**：一致度は「比較に使う特性での近さ（75%）」と「本人の目立つ特性（50点超）がその比較に含まれる割合（25%）」の合計です。本文は前者だけで書いています。後者は「本人の目立つ特性を照合に含む人物を上にする」役割を持つので残しています。
- **構造上の限界**：人物の照合に使う特性は7つ（冷淡・敵意・衝動・操作・危険志向・猜疑・撤退）だけです。不安・依存・固執・完璧・顕示は、どの人物の照合にも使っていません。本人の最上位の特性が照合に入るのは 10〜57% です。そのため、水×依存の人をファトゥスで説明することはできません。本文では、扱っていない特性を「今回の照合では扱っていない」と明記しています。
- **特性の数の違い**：照合に使う特性が1つの人物（ピエロ・プルチネッラ・パンタローネ・タルタリヤ）は、その1特性が近いだけで一致度が高くなります。高めの回答では、1特性の人物が選ばれる割合が 4割を超えます。
- **低い特性だけの人物**：カピターノ・コロンビーナは低い値だけで照合するため、全体に低い回答で偏りやすくなっています（全体に低い回答では、コロンビーナ 52%、カピターノ 44%。全体に高い回答では、ドットーレ 39%、スカラマシュ 24%）。
- **便宜的な値の埋め込み**：不明な特性を50点などで埋めている人物はいません。照合に使わない特性（unknown_axes）として明示しています。

### 2. 改修案の比較（人工回答：一様・低め・高め・相関あり 各4,000件の混合）

| 案 | 人物像の整合 | 本人データとの整合 | 排出の偏り（11名の最大差） | 表示の分かりやすさ |
|---|---|---|---|---|
| A 現状（0.4.0） | 変わらない | 最も近い人物から最大 7.6 ポイント離れた人物を選ぶことがある | ±0.39pt | 一覧の％と並びが矛盾 |
| B 表示だけ分ける | 変わらない | Aと同じ | ±0.39pt | 矛盾は解消（選定は印で示す） |
| **C 近さの下限つき均等化（5ポイント）＋B の表示** | 変わらない | **選ぶ人物は、常に最も近い人物から5ポイント以内** | **±0.32pt** | 矛盾は解消 |
| D 補正なし（最も近い人物） | 変わらない | 常に最も近い | ±5.6pt（3.5%〜13.4%） | 最も単純 |
| 参考：下限2ポイント／3ポイント | 変わらない | 差は最大2／3 | ±3.3pt／±2.0pt | 矛盾は解消 |

**採用：案C。** 均等さを保ったまま、選ぶ人物を本人から大きく離さない条件を加えられるので、四つの観点で最も整合します。

**衝突の明示**：完全な均等と人物の適合性は両立しません。下限を2〜3ポイントに狭めると、偏りは ±2〜3pt に広がります。また、全体に低い回答・全体に高い回答のように偏った集団では、下限の範囲に候補が少ないため、均等にはなりません（下の表）。そうした集団でも、本人から5ポイントを超えて離れた人物は選びません。

### 3. 「均等」の評価条件

- **人工回答の分布**：calibrate.py の4群（一様・低め・高め・共通因子あり）を同じ比率で混ぜたもの。各群 8,250件 × 4 で補正値を求め、別の seed の3群（各33,000件）で確認しています。
- **許容する偏り**：確認群で、各人物の出現率が 9.09% から ±0.75pt 以内であること。spec の検査で確認しており、今回は最大 0.71pt でした。
- **人物との近さを守る条件**：選ぶ人物は、補正前の近さが最も近い人物から **5ポイント以内**（selection_max_gap = 5）。補正値はこの範囲の中でだけ使います。
- **保証しないこと**：人工回答での均等性は、実利用者でも均等になることを保証しません。実利用者の回答の分布は、この混合とは異なりえます。

- 「旧→新で人物が変わる」は、同じ回答で 0.4.0 と 0.5.0 の選定が違った割合です。入れ替わりは 2〜10% で、近さの差の上限は約7〜9ポイントから5ポイントに下がりました。
- 全体に低い・全体に高い回答では、特定の人物に偏ります（最多 52%／39%）。これは参照値の配置によるもので、均等化では補っていません。参照値を動かして均等にすることもしていません。
- 同点：補正後の値が同点のときは、回答から決まる固定の順序で一人を選びます（再表示で変わりません）。表示する一致度は丸め前の値で並べ、同じ値は ID 順です。

### 5. 表示方式（2026-11-10 オーナー指示：1位より2位の一致度が高いのはおかしい → 0.6.0）

- **一致度＝順位に使う値**：表示する一致度を、順位に使う値そのものにしました。値は「近さ＋人物ごとの固定の補正」で、0〜100 に収め、四捨五入しています。上の順位の人物ほど一致度が高くなり、1位より2位が高くなることはありません。
- **補正の大きさ**：補正値は calibrate.py の元の方法（制約なし）でも ±4.74 以内に収まります（ピエロ −0.93、カピターノ −3.98、ドットーレ +4.15、コロンビーナ −4.74、アルレッキーノ +1.82、プルチネッラ +0.86、スカラマシュ +2.53、サンドローネ −1.24、シニョーラ +2.83、パンタローネ +2.27、タルタリヤ −3.56）。spec の検査で、補正が ±5 以内であることを確かめています。
- **0.5.0 の「5ポイントの下限」は廃止**：補正が小さいため、下限を設けなくても、補正前に最も近い人物との差は最大でも約9ポイント（補正値の最大差 8.89）に収まります。表示と順位を一致させることを優先しました。
- **均等さ**：別の seed の確認群（99,000件）で、各人物 8.7〜9.6%（目標 9.09% ±0.75pt 以内）です。人工回答での均等は、実利用者での均等を保証しません。
- **説明**：06 の定義に「一致度は…近さを中心に…11名が偏りなく現れるよう人物ごとに小さな調整（±5ポイント以内）をした値」と書いています。結果ページ・方法説明・診断の説明ページも同じ説明にそろえました。
- **本文**：「近い／離れている」の判定は、補正を含まない、照合に使う特性ごとの本人の得点と参照値の差で書いています。補正は、近さの根拠には使いません。
- **共通の値**：レポート・結果ページ・Xシェアの文・共有ページ・OGP・マイページは、すべて同じ一致度と順位を使います。表記は「あなたのファトゥス」です（OGP の版 dti-og-3）。

### 8. 0.7.0（2026-11-10）：一致度が境界で急変する問題の修正

- **問題**（GPT が実行して確認）：目立つ特性（50点超）が一つもない回答では、目立つ特性の割合が全員 1 になっていました。照合外の特性が一つだけ 50 を少し超えると、全員 0 になります。そのため、全特性50（衝動だけ40）から不安だけを55にすると、全人物の一致度が25ポイント下がっていました。
- **修正**：割合を、事前値 0.5 へ強さ 20 で寄せた、なだらかな値にしました（`(照合特性の目立ち＋20×0.5)÷(全体の目立ち＋20)`）。JS 判定・spec 参照実装・calibrate.py をすべて同じ式にしています。
- **検査**：GPT の再現例では、全人物の変化が3ポイント以内です。照合外の特性を 50→51 にしたときの変化は、1ポイント未満です。どちらも検査に追加しました。
- **再校正**：補正値は ±6.58 以内です。spec の検査の上限を ±7 に改めました。別の seed の確認群では、各人物 8.5〜9.7%（目標 9.09% ±0.75pt 以内、最大 0.63pt）です。
- **代表例**：サンドローネの代表例を、照合特性に沿う回答（撤退・敵意とも高め）に差し替えました。
- **表示**：読者向けの表示からは、重み・補正などの計算説明を外しました。計算仕様と検証記録は、この文書と spec 一式に残しています。
