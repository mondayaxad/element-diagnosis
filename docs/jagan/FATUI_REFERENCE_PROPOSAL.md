# ファトゥス参照値の変更案（未適用・確認用）

作成：2026-11-08。照合表（FATUI_REFERENCE_CHECK.md）の結果をもとにした**判定変更の案**です。文章の修正（作品紹介文・注意書き）とは分けて確認するため、**まだデータには反映していません**。

## 前提

- 全員の参照値は、原作から確定した数値ではなく、DTI 側の**編集上の設定**です。
- 根拠が足りない特性は、低い値や50付近で埋めず、**「未対応」（比較に使わない）**にします。
- 未対応にした特性は、その人物との比較から外れます。一致度は、残った特性だけで計算されます。

## 案A：根拠不足と判断された参照値を「未対応」にする

| 人物 | 変更 | 理由（照合結果） | 変更後に比較する特性 |
|---|---|---|---|
| ピエロ | 猜疑65 → 未対応 | 世界への反逆を、広い対人不信と結びつけない | 敵意75 |
| コロンビーナ | 撤退65 → 未対応 | 「組織を離れた」ことを撤退特性にしない | 敵意20・冷淡20 |
| プルチネッラ | 衝動30 → 未対応 | 別途の根拠がない | 操作75 |
| パンタローネ | 冷淡55 → 未対応 | 不明な特性を中間値に置かない | 操作85 |
| タルタリヤ | 衝動45 → 未対応 | 衝動の程度が未確定 | 危険志向85 |

**この案に入れていないもの（根拠を追加で探すもの）**

- カピターノ（衝動・敵意・冷淡の低さ）
- アルレッキーノ（冷淡30）
- サンドローネ（撤退75・敵意65）
- シニョーラ（操作・冷淡）
- ドットーレ・スカラマシュ：維持候補ですが、数値は編集上の設定と明記します

これらは各特性に対応する場面が見つかるまで、値を変えずに保留します。

## この案で生じる課題

1. **比較する特性が1つだけの人物が4人になります**（ピエロ・プルチネッラ・パンタローネ・タルタリヤ）。一つの特性だけの近さで「最も近い人物」になりやすく、比較の根拠が薄くなります。
2. **出やすさの偏りを補正する値（selection_offset）**は、現在の参照値に合わせて決めています。案Aを採る場合は、補正値の決め直しも必要です。プルチネッラ 27.6%、パンタローネ 1.9% のような偏りが出ているためです。
3. 結果の版（characterModelVersion）を上げる必要があります。すでに保存された結果やマイページの記録との関係も決めます。旧版の結果は旧版のまま表示する、を想定しています。

## 決めていただきたいこと

- 案Aのとおり「未対応」にするか。それとも、根拠を追加で探してから一括で見直すか。
- 比較する特性が1つだけになる人物を、選ばれる対象に残すか。最低2特性を条件にするか。
- 補正値の決め直しと版の更新を、同じ変更でまとめて行うか。
