# 邪眼診断｜実装仕様の確定候補 v1.0 RC1

作成日：2026年11月2日
用途：ユーザーの確認後にClaudeへ渡す、一つに整理した実装仕様。

**実装着手に使える候補であり、公開・販売の検証が済んだ本番システムではありません。** 本番サイト・DB・Stripeへの変更は行っていません。

## 今回整理したこと

- 50問・5段階・12スコアの設計を維持。
- 元素はv0.5の校正候補を、今回の実装用データとして選択。
- 人物は11名。人物本人の心理得点を推定する方式を採用せず、**作品解釈から設計した回答参照パターンとの類似度**を今回の方式として選択。
- 同じ50問から、元素・型・人物を独立に判定する一つのruntime.mjsへ統合。
- 人物の解説11名分、実際の得点差に基づく共通点・相違点、公開用要約、X文を整理。
- 販売価格は1,000円・買い切り1商品に確定。販売は実装・決済確認まで閉じた状態で固定。既存ETIの商品・購入権限へ接続しない。

## これまでの候補との関係

v0.4・v0.5にあった複数のモデルを、実装時に選び直す必要はありません。実装対象は **data/の設定とruntime.mjs** です。

evidence/は背景・仮回答実験の記録。そこにある古い保留データ・元係数・提案ファイルを、本番用設定として読み込まないでください。今回の採用候補の意味と限界はMETHOD_SPEC.mdを参照してください。

以前の「ピエロを含む10名・各10%」は誤りでした。パンタローネを含む11名、各約9.09%が正しい対象・目標です。

## ローカルで確認

```bash
node --test tests/runtime.test.mjs
node generate_examples.mjs
```

参照実装と検査はNode.jsの標準機能で実行できます。evidence/の数値校正スクリプトの再実行にはNumPy 2.3.5・SciPy 1.17.0を使用します。

## 公開までに残ること

実際のサイトへの実装、設問を人がどう理解するかの確認、実機での保存・共有・既存ETIの回帰確認。販売開始には、確定価格1,000円の商品設定・購入権限・決済確認も必要です。

人工回答の結果は実利用者の結果ではありません。11名の出現率が各8.42〜9.53%だったことは、作品解釈の正しさ・心理測定の妥当性・将来の均等な出現を証明するものではありません。
