## 内容審査の焦点
- AUT_S：断る余地の項目は対人スキルとの混同を確認。
- COM_F：課題の難しさと本人の能力への評価が混ざらないか確認。
- REL_S／REL_F：特定の相手と人間関係全般の受け取り方を確認。
- SUPPR：肯定的感情も含む広い抑制を意図。状況依存を確認。
- IMP_D：メッセージを使わない人の欠測、他3問との内容の広がりを確認。
- GOAL_D：感情を伴わない疲労・注意の問題と区別できるか確認。
- 同一領域内の重複と、5段階の選び分けを試行で確認。

理論対応：AUT/COM/REL＝自己決定理論、REAPP/SUPPR＝感情調整プロセスモデル、CLAR/ACC/IMP/GOAL＝感情調整困難モデル。元尺度名の得点として販売しない。
