# 固定した実装候補と未決事項

## 固定する候補

1. 同一サイトの `/jagan/` を独立したTOPとして見せる。
2. 元素診断の受検は不要。独自50問、5段階と別枠の欠測選択。
3. 自己決定理論の充足・阻害6項目、感情調整方略2項目、感情調整困難4項目を参考にした12スコア。
4. スコアは各領域の平均を0〜100へ線形換算。順位・確率・重症度ではない。
5. 7元素と6タイプは独自の解釈。明確な偏りなし、拮抗、回答不足も表示する。
6. 人物はピエロ、カピターノ、ドットーレ、コロンビーナ、アルレッキーノ、プルチネッラ、スカラマシュ、サンドローネ、シニョーラ、パンタローネ、タルタリヤ。
7. 人物の比較先は、物語を参考に作者が設計した利用者側の回答参照パターン。人物本人が心理尺度に回答したという想定ではない。
8. 人物類似度は同じ12座標・共通の重みで距離を計算。割合を見て本番の結果をその都度変えない。
9. 参照パターンの均等化目標は各約9.09%。同一プロフィール、同率を許容する。
10. 既存のマイページに邪眼診断の結果を保存し、後から同じ結果を開ける。
11. 保存・画像保存・X共有は別の操作。公開要約に生回答・12スコアを含めない。
12. 黒に近い夜と暗赤の光。英語筆記体→診断名→サブタイトル→説明→開始。
13. 初期の背景JPG・人物JPGを必須にしない。OGP画像自体は文字と装飾で作る。
14. 邪眼解析レポートは1,000円・買い切りの1商品に確定。内容紹介とサンプルの後、最後に価格・購入ボタンを置く。追加プラン・段階別商品・サブスクリプションは設けない。
