# 実装後の公開前確認

## 実装仕様の確認

- [ ] 50問・12スコア・7元素・6タイプ・11名のデータと版が一致する。
- [ ] 作品解釈の人物参照パターンという方法を説明している。
- [ ] 同率・拮抗・偏りなし・欠測の例で、強い特徴や原因を作っていない。
- [ ] 人物の物語と、利用者の数値が近い項目を混同していない。
- [ ] 設問を実際に読んだ人がどう理解したか確認し、修正が必要な文を記録している。

## 画面・操作

- [ ] TOPから50問、結果へ進み、戻る・回答変更・リロード・連打でも回答が壊れない。
- [ ] 実際のスマートフォンで5段階と欠測選択を押せる。
- [ ] 長い人物名・型名、同率候補、判定保留が読める。
- [ ] 背景・人物JPGがなくても成立し、OGP生成の失敗で結果を止めない。
- [ ] 画像保存の生成中・失敗・再試行が使える。

## 保存・共有・権限

- [ ] 未ログインの保存→認証→保存成功→再表示が通る。
- [ ] 再試行で重複せず、別の本人の結果に上書きできない。
- [ ] 保存した版と結果を再現できる。
- [ ] 別アカウントから非公開結果・レポートを取得・更新・削除できない。
- [ ] マイページに邪眼結果が追加され、元素診断結果を上書きしない。
- [ ] 共有は本人操作で作成され、生回答・12スコア・非公開IDを公開しない。
- [ ] 共有ページ・OGP・X文・画像保存が同じ版の要約を示す。
- [ ] 削除済み・期限切れ・無効な共有URLで非公開データが返らない。
- [ ] 保存と共有取消・削除・保持期間の案内が現行運用と整合する。
- [ ] GA4のイベントと自動ページ情報に心理スコア・回答・非公開コードがない。

## 販売する場合に追加

- [ ] 1,000円・買い切り1商品の設定が反映され、内容紹介の最後に価格がある。
- [ ] sales_open=falseまたはprice=nullでは購入を開始できない。
- [ ] 商品・結果・本人の購入権限をサーバーで確認している。
- [ ] 既存ETIの商品・価格ID・旧購入を流用・破壊していない。
- [ ] 決済後の復帰、再訪、未購入者の拒否を確認している。

## 既存ETIと公開

- [ ] ETI v2の100問・採点が変わっていない。
- [ ] ETIの保存・共有・旧購入引継ぎ・共有経由購入・認証復帰が動く。
- [ ] マイページの既存の購入ランクと最新観測の扱いを維持している。
- [ ] プレビュー結果・未確定値が本番履歴へ混入しない。
- [ ] 公開対象HEAD、DB適用順、環境、戻し方を確認している。

本資料でチェック済みなのは参照実装の計算・境界検査です。上記の実機・DB・決済・本番検査は未実施のため、空欄のまま引き継ぎます。
