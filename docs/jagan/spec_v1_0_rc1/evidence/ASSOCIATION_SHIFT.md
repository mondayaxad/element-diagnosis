# 連想モデル：回答傾向を変えた仮回答での確認

混合条件で均等に近づけた人物連想モデルを、学習に使っていない異なる条件の仮回答へ適用した。人工データのみで、実利用者の出現率ではない。

| 人物 | 低困難条件 | 高困難条件 | 表出抑制多め条件 |
|---|---:|---:|---:|
| ピエロ | 4.78% | 9.27% | 16.85% |
| カピターノ | 19.58% | 2.60% | 6.13% |
| ドットーレ | 9.04% | 5.27% | 4.20% |
| コロンビーナ | 4.56% | 11.11% | 2.42% |
| アルレッキーノ | 12.38% | 4.45% | 22.25% |
| プルチネッラ | 9.45% | 5.29% | 8.62% |
| スカラマシュ | 2.25% | 27.47% | 7.56% |
| サンドローネ | 7.36% | 6.38% | 2.53% |
| シニョーラ | 4.56% | 12.25% | 16.84% |
| パンタローネ | 4.45% | 13.27% | 10.27% |
| タルタリヤ | 21.56% | 2.62% | 2.33% |

これらの集団を各9.09%に合わせ直してはいない。回答の傾向が変われば人物の割合も変わる。混合条件での均等化は、全ての集団での均等な出現を保証しない。

次の評価では、こうした分布の変化を含めて、各回答と人物の連想に無理がないかを人が確認する。数値上の均等さを原作との整合の証明としない。
