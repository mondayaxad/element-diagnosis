# 11名の参照パターン案：レビュー用

人物本人の心理得点ではなく、物語を連想させる回答パターンとして作者が置いた値。全軸が設計上の仮説を含む。原作に各点数が設定されているという意味ではない。表示は整数へ丸めており、JSONを機械可読の正本とする。

校正の±10点は技術上の実験制限であり、心理学・原作上の許容範囲を証明する値ではない。

## レビューする点

- 感情の困難が高い利用者を、人物の悪意・加害性まで似ているとしない。
- 冷静さ、献身、研究、政治的手腕を、直接測っていない動機・能力の証明にしない。
- 数値の差を原作の細かな違いの証明としない。同一プロフィールも許容する。
- 均等化の数値がよくても違和感の強い連想は修正する。
- 元の候補を残し、修正後は別の人工回答群で再評価する。
