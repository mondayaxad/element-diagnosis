# 人物比較の根拠審査 v0.5

## 対象の訂正

v0.3・v0.4ではパンタローネが一覧から抜けていた。正しくは、名前の挙がっていた現旧執行官10名に統括官ピエロを加えた11名である。今回の対象に未知の第十位や先代召使を追加するという意味ではない。

均等化の目標は1/11＝約9.09%。旧資料の「10名・各10%」より本書を優先する。

## 今回の追加確認

パンタローネ：聖遺物「停頓の時」、夜蘭の物語・任務、アルレッキーノとコロンビーナのボイスをWiki経由で確認。財力、計画の持続、抑えられた憎しみに関する他者評価を区別する。貧困の過去から現在の有能感阻害を高くしたり、憎しみがあることから衝動調整困難を高くしたりしない。

コロンビーナ：プロフィールの所属期を記したストーリー2には、選択が与えられる経験、期待される役割の拡大、本人が歓迎されていないと感じる経験が記される。所属期の自律性・関係性を考える資料になるが、後年の居場所への充足と混ぜない。

ピエロ：嗤笑の面では悔恨と大義が語られる。ただし怒りを抱くことは、感情を受け入れられないことや、感情下で行動を止められないことを直接示さない。

## 12項目との対応審査

以下は数値に置き換える前の方向性審査。「検討可」はキャラクターが同じ尺度を受検したことを意味しない。行動からの推定は、本人の自覚を尋ねる今回の設問と完全には同じではない。

| 人物 | 比較に結びつけて検討できる描写 | 対応の候補 | そのまま点数にできないもの |
|---|---|---|---|
| ピエロ | 破局への悔恨、長期の大義、組織を通じた活動 | 行動維持の低困難という推定 | 悔恨＝感情受容困難、天理への反逆＝自律性阻害 |
| カピターノ | 使命の持続、対立後も目的のため協働 | 行動維持の低困難という推定 | 献身＝衝動性、方針変更＝認知的再評価の使用頻度 |
| ドットーレ | 研究・交渉の持続、複数切片とその取引 | 行動維持の低困難という推定 | 研究者＝感情理解が得意、非道＝感情受容困難 |
| コロンビーナ | 所属期に感じた選択の余地、役割への圧迫感、置き去りの感覚 | 自律性阻害・関係性阻害の状況依存の解釈 | 神秘性＝感情理解困難、他人が読めない＝表出抑制 |
| アルレッキーノ | 感情を認識して扱う指導、冷静な実務 | 感情理解・行動維持の低困難という推定 | 指導する＝本人もいつもできる、冷静＝表出抑制が常に高い |
| プルチネッラ | 政治的手腕と継続する対人関係への働きかけ | 行動維持についての限定的推定 | 世話＝本人の関係性充足、政治的操作＝特定の欲求阻害 |
| スカラマシュ | 当時の裏切りの受け止め、目的への持続 | 関係性阻害の解釈、行動維持の状況差 | 裏切りの経験＝常に全ての困難が高い |
| サンドローネ | 研究の持続、相手・場面で異なる反応 | 行動維持についての推定 | 怒った＝衝動制御不能、対人評価が悪い＝本人の孤立感 |
| シニョーラ | 喪失後の目的遂行、外交、物理的な炎の抑制 | 行動維持についての推定 | 悲嘆＝感情受容困難、氷の邪眼＝表出抑制得点 |
| パンタローネ | 長期の経済計画、抑え込まれた憎しみという他者評価 | 行動維持・感情表出についての推定 | 憎悪＝感情の非受容、野心＝有能感阻害 |
| タルタリヤ | 家族とのやり取り、挑戦と任務の持続 | 特定関係の充足、行動維持についての推定 | 戦闘好き＝衝動調整困難、強さ＝本人の充足得点 |

## 数値化を止めている理由

今回の12項目は「最近の自分がどう感じ、どう行動するか」を自己報告する設計。一方、物語で読めるのは限られた場面・他者評価・過去の内面である。特に『感情がつらいときの行動維持』について、単に職務を続けているという描写だけでは同一の得点にできない。

したがって、全11名に共通して根拠付き数値へ確定できた項目集合は、現時点で未確定。データファイルのnullを0、50、100へ自動的に置換しない。人物を均等に出すために研究で未測定の内面を断定しない。

この問題は、まだコードがないことではなく、比較モデルの根拠の問題。人物の参照値を創作的に設計する場合でも、「公式描写から直接確認した値」と「作品解釈の仮説」を各軸で区別してレビューする必要がある。人物の登場割合だけで参照値を採用しない。

## 次に判定すべき具体的な点

1. 行動の描写から自己報告の頻度へ置き換えられない軸は、人物照合で採用しない。
2. 共通軸を絞ったとき、人物が区別できなくなっても同率を許容する。
3. 同率だらけなら、全11名の精密な一致率を計算できたとはしない。
4. 11名の差を表すのに、現行12項目にない動機・価値をどうしても必要とするなら、質問本文を最終確定する前に測定構成を見直す。
