# 採点・解釈・人物類似度

## 12項目の心理スコア

質問は独自作成。元のBPNSFS・ERQ・DERSの質問票やその得点としては扱わない。これらに関連する理論・構成概念を土台にした独自の設問である。

各領域は順方向の回答1〜5を平均し、`(平均-1)*25` で0〜100へ換算する。充足と阻害は別々に保持し、片方を反転して他方を作らない。4問領域は3回答以上、5問領域は4回答以上で参考得点を計算。欠測を0・中間点で埋めない。

部分回答の数値は参考値として表示する。領域に回答不足があれば、その領域を必要とする判定は保留する。人物比較は12項目を全て使うため、1領域でも算出できなければ人物を出さない。

## 元素

data/interpretation.jsonにある重みを使う。正の重みは得点、負の重みは `100-得点` を使い、絶対重みで加重平均する。元の測定スコアは反転・変更しない。

元素への対応は作品の象徴を借りた独自解釈であり、心理学上の7分類ではない。各元素に寄与する領域の全てが高いと説明しない。

元の項目と符号を保った人工データによる校正候補を今回の実装に選択した。係数を調整したこと自体が科学的妥当性を示すわけではない。

## 型

捉え直し、表出抑制、衝動調整困難、行動維持困難、感情理解困難、感情受容困難の6得点を解説用に整理する。タイプの境界や順位は心理学的に実証された人格分類ではない。

最大値が60未満なら「型の偏りなし」。最大値との差が3点以内の有効候補は拮抗として記録する。60点と3点は設計上の暫定基準であり、一般人口の基準ではない。

## 人物との比較：今回選択した方式

比較するのは人物本人の心理得点ではなく、人物の物語から作者が提案した「回答参照パターン」。全ての参照値は解釈の仮説を含み、公式に数値化されたキャラクター設定ではない。

この方式を選んだ理由は、原作の描写から11名全員の自己報告に相当する心理得点を確定できなかったため。未知の内面を確認済みとして埋める方式をやめ、参照パターンそのものが作者の解釈であることを明示する。

```
距離 = sqrt( Σ 重み × ((回答得点 - 参照値) / 100)^2 / Σ 重み )
類似度 = 100 × (1 - 距離)
```

全員に共通の12座標と重みを用いる。欲求6項目、方略2項目、困難4項目の3群が、それぞれ合計1/3を占める。研究で最適と証明された重みではない。

表示例は「最も近しいファトゥス：スカラマシュ（87%一致）」。方法説明で、独自の参照パターンとの近さであり、科学的な人物一致確率ではないことを説明する。

類似度への一律加算、最低80%などの補正は行わない。丸め前の値で順位と同率を計算し、表示だけ整数にする。

## 均等化と再現性

仮回答群を使い、作者の初期参照値から各軸±10点以内で候補を調整した。この幅は技術上の制限であり、設定を守れていることを保証する範囲ではない。

独立した人工回答5,500件では各8.42〜9.53%。低困難・高困難・表出抑制多めという別条件では割合が変化した。全ての集団・全ての期間で同じ割合になるとはしない。

公開中の参照値と重みを固定し、現在の人数・売上・アクセス状況で結果を変えない。真の同率だけ、結果IDに基づく安定した選択で代表を決める。同じ結果IDなら再表示でも同じ。別の新規受検では真の同率群の代表が変わる場合がある。

人物側の戦闘元素を利用者の邪眼元素に直結させない。型や元素を人物1人ずつの専有結果にしない。

## 解説の作り方

物語の説明と、利用者の得点から分かる内容を分ける。explainCharacterは参照パターンとの点差が小さい項目・大きい項目を返す。15点以下・20点以上という閾値は説明のための設計値であり、臨床的な意味はない。

近い項目がないときに共通点を作らない。差が小さいときに相違を作らない。総合1位でも、その人物全体と強く一致しているとは説明しない。

高い困難の回答から、人物の悪意・加害性・病気まで似ていると推定しない。物語の因果を利用者の人生の原因として流用しない。
