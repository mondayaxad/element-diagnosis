# 画面仕様

## TOP

同一サイトの独立ページ `/jagan/`。既存元素診断の構成を参考に、英語筆記体「Delusion Diagnosis」→「邪眼診断」→「あなたの願いは、どんな深淵を映すのか。」→短い説明→「診断をはじめる」。

背景#09070B、カード#160D14、主ボタン#A52A43、本文#EFE5E8、補助文字#BDA9B0。細い線と暗赤の光。実装時にコントラスト・押下・フォーカスの視認性を確認する。

## 質問

3ブロック、進捗、戻る、回答変更、5段階の言葉を読める表示、別枠の「判断できない・回答しない」。色だけで選択状態を伝えない。連打で2問進まないようにする。

設問順はdata/items.jsonのdisplay_orderを使用。IDを表示位置で置き換えない。最近1か月という教示を開始時と必要な区切りで確認できるようにする。回答速度だけで無効としない。

## 完了画面

1. 小見出し「あなたの深淵」。
2. 大きく「邪眼元素 × 型」。型に偏りがなければ「型の偏りなし」。
3. 短い解説を2段。元素の象徴説明と、今回の型・実際の寄与項目を説明する。未測定の動機・原因を補わない。
4. 「最も近しいファトゥス：名前（整数%一致）」。方法説明を開ける。近接・同率があるときは、その旨を表示。
5. 「あなたの渇望する邪眼」：上位3元素。真の同率を1位・2位・3位の客観的な差として見せず、必要なら「他にも同率候補あり」。
6. 「マイページ保存」「画像保存」「Xシェア」の順。小さい画面は読みやすい幅で折り返す。
7. 「ここで見えているのは、あなたの深淵の一部分に過ぎません。」→レポート内容→サンプル→価格と購入ボタン。

欠測で人物・元素が判定できなければ、その部分を「回答不足のため判定保留」。例示の人物名や数値で穴埋めしない。回答の見直しへ戻れるようにする。

## 人物解説

物語の説明はdata/character.copy.json。利用者との比較はexplainCharacterの実際の結果に基づく。共通点は「参照パターンに近い項目」、相違点は「参照パターンと差のある項目」として見せる。人物の真の内面を測定したように説明しない。

1位と2位の差が小さいことを隠さない。丸めて同じ%になっただけの場合と、計算上の真の同率を区別する。

## レポートと販売未開始時

「邪眼解析レポート」は1,000円・買い切りの1商品。12スコアの意味、元素・型の判定理由、近しい人物候補と相違、振り返りの問い、方法説明を収録する。

販売価格は1,000円で確定。案内の末尾に「邪眼解析レポート 1,000円／買い切り」と表示する。販売設定・購入確認が済むまでは「レポート準備中」とし、購入操作を開始しない。既存元素診断の商品へ送らない。購入確認後に確定価格と購入条件を添えた購入ボタンを有効にする。

## 保存・画像・共有

保存は認証を跨いでも結果を失わせず、既存マイページ内に邪眼結果として表示。保存の成功・失敗・再試行を明示する。

画像保存は押下時に生成。生成中や失敗で他の操作を止めない。OGPは公開要約を赤黒い結果カードにし、背景JPG・人物JPGを必須にしない。フォント・生成・配信の時間は実装後に計測する。

X共有はmakeShareTextの形式。共有内容を確認できるようにし、Xの投稿画面で本人が確定する。自動投稿しない。

## 方法説明

data/method.copy.jsonの内容を `/jagan/about/` 等で読めるようにする。結果画面は短い説明とリンクを基本にし、長い方法説明を開始・保存の前に毎回強制表示する流れにはしない。
