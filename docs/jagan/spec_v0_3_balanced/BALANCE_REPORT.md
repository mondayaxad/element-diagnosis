## 読み方

全体の均等化はこの混合比率に対して成立する。低い回答が多い集団、高い回答が多い集団、実利用者でも同じ率になる保証はない。実運用でカウンターを見て当選者を入れ替える方式ではない。

人物の座標は未知軸を補完しない部分的な物語参照。数値は作者の設計仮説であり、人物本人の心理得点ではない。均等化ができても、その解釈や測定精度が正しいことにはならない。
