# 12特性・11名の均等化判定 v0.3

先にSPEC.md、次にBALANCE_REPORT.md、EXAMPLES.mdを読む。

今回の成果は、新しい12特性・50問を維持したキャラクター選択の再構成。人物参照を固定し、人工回答の基準分布で各約9.09%へ近づく固定補正を追加した。ライブの人数割り当てや毎回の抽選ではない。

## ファイル

- items.json / QUESTIONS.md：50問、12特性。5問ずつ、5段階のみ。冒頭説明画面・補助選択肢なし。
- core-model.json：邪眼・異相の候補係数。人物の均等補正と分ける。
- characters.json：部分的な物語参照、未知の軸、11名の特徴二語・地域表示・出典・固定補正。
- runtime.mjs：JavaScriptの参照実装。
- calibrate.py：再現用の人工回答生成と固定補正の学習。numpy、scipyが必要。
- BALANCE_REPORT.md / balance-report.json：補正前後・独立確認群・集団別の出現率。
- EXAMPLES.md / examples.json / examples.mjs：代表回答の計算例。
- parity-fixtures.json / check.mjs：計算整合性と境界等の確認。

実行：node check.mjs。計算例の再生成：node examples.mjs。補正再計算：python3 calibrate.py（characters.json等を再生成する）。

## 前の版との関係

旧10特性の座標や補正は使っていない。12特性版の設問を読み、各人物に対応を置ける軸だけを使う比較方式へ変更した。未知の内面を50点等で埋めない。人物の数字は独自の連想用の設計値であり、公式の心理得点ではない。

この版は判定データ・参照実装であり、実サイトのデプロイやDBの変更は行っていない。先に渡したClaude用ZIPと統合する場合は、この版を人物判定の候補として使い、旧12軸の欲求モデルや旧10特性版と混ぜない。

料金は邪眼解析レポート1,000円の買い切り一商品、表示は「邪眼元素 × 異相」を維持する。学術的な基準から直接決まらない重み・境界・人物対応は独自設計として説明する。
