# 改善後の独自設問50問（検討用）

50問・5段階・5問ずつ・補助選択肢なし・冒頭説明画面なし。元尺度の特性概念を参考に独自起案したもので、正式なPID-5ではない。

依存と衝動は各5問、そのほか10特性は各4問。4問で十分な精度があるとはまだ検証していない。合計点ではなく、回答平均を得点化する。
