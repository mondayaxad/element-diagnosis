# 11名の出現率を均等に近づける再構成 v0.3

2026年11月3日。対象はキャラクター11名。12特性の測定、50問、7元素と異相の基本構成を維持する。元素や異相の出現率まで均等へ合わせる変更ではない。

## 今回変えた点

1. 12特性のうち、作品描写と対応を検討できる部分だけを、人物の物語参照へ用いる。
2. 未確認の特性を50点等で埋めず、比較対象から外す。
3. 人物参照を固定した後に、人物ごとの出やすさを調整する固定補正を計算した。
4. 別seedの人工回答99,000件で、出現率を確認した。

人物の「参照値」は作者が設計した物語との連想用の仮説であり、人物本人に質問票を実施した心理得点ではない。資料から数値を定量推定できたという意味でもない。解釈の弱い箇所はcharacters.jsonのrationaleにも残す。

## 特性・邪眼・異相

各特性の回答平均を0〜100へ換算する。項目数が4問と5問で異なるため合計値で比較しない。独自の尺度であり、公式PID-5の得点や百分位ではない。

異相は最高平均の特性を要約する候補とし、60点未満は未顕、60点以上の最高が同点なら複合とする。60点や僅差5点は表示上の仮基準で、臨床的な閾値ではない。異なる特性の得点差が、心理的な強さの差として等間隔であると検証できたわけではない。

元素の係数はcore-model.json。複数特性から導く独自の物語的な象徴であり、原作や心理学の公式対応ではない。最高が同点なら未分化を候補にし、無理な順位を付けない。

人物の補正はこの特性得点、邪眼、異相に影響しない。

## 人物参照の比較範囲

今回の人物比較で、直接対応を置いた軸の和集合は、猜疑・撤退・衝動・敵意・操作・危険志向・冷淡の7軸。12特性全ての人物内面を確認できたとは扱わない。

人物ごとに2〜3軸の部分参照を置く。例えば博士は操作・冷淡、タルタリヤは危険志向・衝動を分けて扱う。コロンビーナには依存の参照を置かず、帰属への願いと依存を同一視しない。未知の軸はunknown_axesへ記録する。未対応の特性が、本人には存在しないという意味ではない。

カピターノの責務・献身、コロンビーナの帰属等の二語は、人物を紹介する作品解釈。その内容を利用者から直接測れたとは説明しない。人物一致は、限られた比較内容に基づく独自の物語参照である。

## 補正前の類似点

人物に対応を置いた軸だけで、利用者得点との距離を計算する。

- 対応度A：100×［1−sqrt（参照を置いた軸の「差÷100」の二乗平均）］。
- 関連度C：利用者の各特性についてmax（得点−50, 0）を求め、その合計のうち、人物に対応を置いた軸が占める割合。全て50点以下ならC＝1。
- 元類似点S：0.75×A＋0.25×100×C。

関連度は、測定した中で目立つ内容を人物参照がどの程度扱っているかを考慮する独自の係数。原理論から導かれた式ではない。未知軸を中立値として距離に入れることとは区別する。

0.75・0.25・50という値は今回の設計値であり、外部データで正しさが確認された重みではない。狭い参照から人物全体の類似を測れたとは説明しない。

## 均等化の計算

選択点＝元類似点S＋人物ごとの固定補正b。

選択点が最大の人物を表示する。目標は基準とする人工回答分布で各1/11、約9.09%。固定参照の数値や設問を出現率に合わせて動かすのではなく、選択境界を調整する。

前回の「元の最高類似点から5点以内」という制約は、今回の均等化では維持していない。この制約は以前こちらが提案した候補であり、均等化を優先する今回の再構成では外した。補正は平均0に揃え、今回の結果は約−6.52〜＋4.51点。

主確認群で、補正前と人物が変わったのは23.33%。元の最高類似点と選定人物の元類似点の差は、平均0.65点、95%点4.43点、最大11.01点。したがって、単純な元類似点一位を常に返す方式ではない。

最終表示の「最も近しいファトゥス」は、この固定補正を含む独自選定であることを方法説明で明示する。表示する一致度は元類似点Sの整数丸めとし、補正bを加えて数値を高く見せない。

採用する方法説明案：

> 作品の描写に重ねた独自の参照と比較し、人物ごとの出現の偏りを補正して選定しています。一致度は、選ばれた参照への近さを表す独自の指標です。人物全体や、善悪が一致する割合ではありません。

## 同じ回答の安定性

- 同じ50回答は、キーの並び順や再アクセスによらず同じ結果になる。
- 運営中の累計人数を見て人物を入れ替えない。
- 利用者ID、時刻、毎回の乱数を使わない。
- 厳密な同点だけは、設問IDと回答値から作る固定ハッシュで選ぶ。
- 判定版を保存し、更新後も過去の結果を別の意味へ自動変換しない。

## 人物を絞れない回答

比較に使える7軸の最大値と最小値の差が10点未満なら人物判定を保留する。全問同じ値の回答や、未対応の分離不安だけが高い回答から、特定人物を無理に出さない。10点も仮の表示基準であり、回答の不正検出・科学的な信頼性判定ではない。

独立確認99,000件では24件が保留。出現率の分母は人物を出した98,976件である。全問を回答済みでも、人物の比較に十分な差がなければこの例外を使う。補助選択肢やスキップを追加する指示ではない。

## 均等化の結果と限界

訓練33,000件、調整に使わない別seedの確認33,000件×3群。独立確認群それぞれで、出現率は8.65〜9.66%。99,000件を合算した人物判定98,976件では8.84〜9.43%。

基準分布は、一様・低め・高め・共通因子ありを各25%混ぜた人工回答。実利用者の分布を代表すると実証されたものではない。この基準において均等に近づいたのであり、どの回答集団でも9.09%ずつになる保証ではない。低めの集団ではカピターノ等、高めの集団では博士等の出現が増える。集団別の率もBALANCE_REPORT.mdへ掲載した。

均等化のために利用者を実運用の人数枠へ割り振る方式ではないため、同じ回答への結果を保てる。実利用者に偏りがあれば率は変わり得る。その際は、別途得られた適切なデータで固定補正の新しい版を検討する。個人の結果をその場の人数都合で変えない。

## 確認したもの

check.mjsで、設問数・項目配分、未回答・不正入力、同点・平坦な回答、代表パターン、繰り返しの安定性、独立確認群の出現率、PythonとJavaScriptの計算一致等を確認する。

代表パターンは作成者が設けた回帰用の例であり、キャラクターの正解を客観的に検証するデータではない。元尺度と同等の測定精度、人物解釈の客観的正しさ、実利用者の均等出現は未検証。launch_readyはfalseとし、プレビューで確認するための判定候補として渡す。
