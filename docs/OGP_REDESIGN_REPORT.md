## 3. 現行 `api/og-image.mjs` の監査結果

| 項目 | 現状 |
|---|---|
| 生成方法 | `@vercel/og` 0.6.3 の `ImageResponse`（内部は Satori）。Edge Runtime。1200×630 |
| 書き方 | `h()` ヘルパーで要素ツリーを組み立てている（JSXは使っていない）。**今回の `ogp-card.mjs` と同じ形なので、そのまま差し込める** |
| データの受け渡し | `/api/share` が `p` パラメータを `og:image` に渡す。`p` は「元素・武器・国家・キャラ番号・一致度」を1つの数値に詰めた36進数。旧形式（`el` / `w` / `nat` / `c` / `m`）にも対応 |
| ETIコード・タイプ名 | 元素＋武器のコード（例 HYSW）と、元素×武器のタイプ名表から作っている |
| キャラクター | `CHAR_NAMES` 118人の番号 → 名前（**元素の情報は持っていない**） |
| 日本語フォント | Google Fonts から Noto Sans JP 700 を、**表示する文字だけ**にサブセットして TTF で取得（古いブラウザを装って WOFF2 を避けている） |
| 背景画像の埋め込み | 可能。**ただし JPEG / PNG のみ**。**WebP は @vercel/og 0.6.3 で描画エラーになることを実際に確認した** |
| CSSの制約 | flex レイアウトのみ（grid は不可）。absolute 配置、linear/radial-gradient、border、boxShadow、textShadow、backgroundClip:text、SVG の img は使える（今回すべて実際に描画して確認）。**CSS filter は使っていない**（明るさは overlay で代用） |
| 既存URLとの互換 | `/api/og-image?p=…` と旧形式のパラメータはそのまま使える。**URLの形式は変えない** |

現行の不具合（刷新で解消されます）：
1. 円環の放射線が回転の基準点のずれで外周ノードに届いておらず、中央付近で散らばっている（`current_og_1200x630.png`）。
2. 「ELEMENTAL RESONANCE MAP」の一部の文字が、フォントのサブセットに含まれていないため、別のフォントで描画されて混ざっている。

## 5. 7元素に展開するときの変更箇所

1. **`js/ogp-theme.mjs` の `OGP_ELEMENT_THEME` だけ**を調整します。色は辞書にまとめてあり、コードの他の場所には散らばっていません。
2. **中央のモチーフ**：`motifSvg()` に元素ごとの分岐を足します（例：炎＝揺らめき、雷＝放電の細い折れ線、風＝流線、草＝葉脈、氷＝結晶の六方、岩＝層）。今は水だけ専用（`motif: 'ripple'`）で、他の6元素は共通の光の球で仮置きしています。
3. **背景**：まず共通の背景1枚と元素色のにじみ（方法A）で7元素を並べ、足りなければ元素別の背景（方法B）に切り替えます。どちらの場合も `backgroundUrl` を差し替えるだけです。
4. **キャラクターの元素（Edge 側）**：`og-image.mjs` は `characters118_v2.js`（ブラウザ用のグローバル変数）を直接読めません。そこで、既存データから **名前→元素の対応表を機械的に書き出した小さなモジュール**を追加します。
   - 判定ロジックは新しく作りません。
   - 118人全員が、共有URLのキャラ番号の名前一覧と `characters118_v2.js` の両方に存在することを確認済みです。

## 8. 7元素の正式背景の実装（2026-10-01 追記）

### 8-1. 実装内容

**背景ファイル**
- 受け取った7枚（1731×909）を、`assets/ogp/backgrounds/<元素キー>.jpg` に変換しました。
  - サイズは 1200×630、JPEG の baseline、各約100KB です。
  - @vercel/og は WebP を描画できないため JPEG にしています。

**背景の切り替え**
- `js/ogp-theme.mjs` に次の3つを追加しました。

| 追加したもの | 役割 |
|---|---|
| `OGP_BACKGROUND` | 元素キー → 背景のパス |
| `backgroundFor(元素)` | 既存データの元素値（「水」など）からそのまま背景を選ぶ。新しい判定ロジックはない |
| `OGP_NODE_CLOCK` | 正本の配置（12時=炎、10時=草、8時=岩、7時=風、5時=雷、4時=氷、2時=水） |

**二重描画をしない**
- 正式背景には円環・ノード・中央光が描き込まれています。
- そのため、背景を使うときは SVG の円環と元素光のにじみを描きません。
- 背景なし（`?bg=0`）のときだけ、SVG の円環を正本の7元素配置で描きます（fallback・検証用）。

**明るさの調整**
- 正式背景を、文字が主役のまま見えるように、次のとおり調整しました。

| 調整 | 変更前 | 変更後 |
|---|---|---|
| 全体の減光 | .42 | .25 |
| 左側の暗いグラデーション | .84 → .62（48%）→ .24 | .84 → .62（42%）→ .18（62%）→ .10 |

- 文字が置かれている範囲は今までどおり暗いままです。円環の中心付近の実効的な明るさは約 .65 です。

**確認用 fixture**
- `js/ogp-fixtures.mjs` を追加しました。デモは `?element=pyro|hydro|electro|cryo|anemo|dendro|geo` で切り替えられます。
- 一致度は、4段階の色がすべて見えるように散らしています（91 / 85 / 82 / 79 / 77 / 74 / 68）。
- MIRROR のキャラクターは各元素の代表キャラにしました（胡桃・ニィロウ・八重神子・甘雨・放浪者・ナヒーダ・鍾離）。名前の色は `characters118_v2.js` の `element` をそのまま使っています。

**変えていないもの**
- ETIコード、タイプ名、タグ、MIRRORカード、一致度、下部の文、フレーム、フォント、余白、比率、@vercel/og の構成

### 8-2. 受け取った背景の検証結果（要確認）

円環上の点灯ノードを、角度を測って照合しました。

| 元素 | 点灯位置（実測） | 正本 | 判定 |
|---|---|---|---|
| 炎 | 12時 | 12時 | ✓ |
| 水 | 約2時 | 2時 | ✓ |
| 雷 | 5時 | 5時 | ✓ |
| 風 | 7時 | 7時 | ✓ |
| 草 | 10時 | 10時 | ✓ |
| **岩** | **約7時（風と同じ位置）** | 8時 | **✗ 位置が誤っている** |
| **氷** | 約4時だが、他の6枚の「4時」ノードより約60px下 | 4時 | △ 座標がそろっていない |

対応として、正式背景の**岩と氷は位置を補正した版**を実装しました。

- 7枚は円環以外の背景がほぼ同じです（左側の平均差は約1/255）。そのため、次のように補正しました。
  1. 誤った位置の点灯ノードを消し、水の画像の同じ場所（消灯ノード、またはノード無し）で埋めます。
  2. 点灯ノード本体と内側の光を、正しい座標へ移します。
- 補正前後の比較：`fix_geo_before_after.png`、`fix_cryo_before_after.png`
- 受け取った原画像は手元にそのまま残しています。デザイン側で正しい位置の画像を作り直していただければ、同じファイル名で差し替えるだけで反映されます（その方が光の質感は確実です）。
- 補正版の氷は、点灯ノードの外側の淡い光が元画像より少し小さくなっています。

### 8-4. 本実装（`api/og-image.mjs`）で変える箇所
- 描画部分を `buildOgpCardTree(d, { origin })` に置き換えます。
  - `origin` はリクエストのURLから取ります。
  - 背景は `origin + /assets/ogp/backgrounds/<key>.jpg` を Satori が取得します。
- キャラクター名 → 元素の対応表を、`characters118_v2.js` から書き出したモジュールとして追加します。
- フォントのサブセットに、ヘッダー・数字・記号を含めます。
- `p` パラメータとURLの互換はそのまま残します。
