## 2. 時系列の対応

### 2-1. 購入の流れ・リンク（10/20 午前）
- 決済後は中継ページを挟まず、購入したレポートへ直接戻る。アドレスバーは期限のない固有リンクに書き換える。
- 請求書（Stripe）の説明欄・カスタムフィールドにリンクを載せる（URL が長い時はカスタムフィールドを省く）。
- 決済ページに価格・提供時期・返金方針を表示。放棄した決済は購入完了ページに出さない。
- 実際のレポートの PDF 保存が iPhone で失敗する問題を修正（html2canvas・jsPDF を固定版・SRI 付きに）。アラート（ダイアログ）は廃止。
- 注釈（PDF・共有など）を全面撤去。「LOCKED」表記もマイページから廃止。
- 「マイページに登録する」を完全解析の欄の外（最下部・PDF の隣）へ。X への自動の紐付けをやめ、ログイン済みのブラウザでも通常の登録画面を通す。ボタンは単色パープル。
- 画像の出自を記録（運営者の申告：すべて GPT の画像生成）。

### 2-3. マイページの購入状態（10/21）
運営者の指摘を受けて直したもの。
1. **ボタンの縮尺**：狭い画面で各ボタンが縦に約250px 伸びていた（列方向の flex の基準値が原因）。高さ 44〜50px に。
2. **並びと色**：A 購入済みの記録は、完全解析（B）を上、「解析レポートを読む」を下に。上のボタンに元素ごとのグラデーション（記録の `--lc` / `--lc2`）。
3. **購入が見た目に反映されない**：マイページ・固有リンクで買って登録した納品（registered deliveries）を、紋章・バッジ・INSIGHTS の数・COMPLETE 判定が見ていなかった。登録済みの納品も数えるようにした。
4. **状態のルール（運営者の指定）**：A のみ＝INSIGHT／B のみ＝INSIGHT／A＋B＝COMPLETE。「集めてきた記録章」の欄には COMPLETE・INSIGHT を出さない。「これまでのあなた」の NEW と COMPLETE は1行に収める（狭い画面では右端に上下で重ねる）。
5. **追加の監査（11項目）**：同じ結果のゲスト記録と自分の記録が2枚出て片方が ¥1,000 を求める問題→購入を表に出る記録へ寄せる、右上「レポート」の画面に購入済みの価格が残る→購入ボタンの横だけに価格、記録選択の文言（作成中・停止中）、作成失敗時の矛盾した文言、決済直後の登録の再試行（payment_pending）、作成中の完全解析の自動更新（15秒・最大約5分）、ほか。
6. 結果ページ：マイページの記録（`#rec=`）から開いた時、保存の欄を「✓ マイページに登録済みです」に。

### 2-4. サンプル・表示の正確さ
- **解析レポートのサンプル**：実際の解析レポート（最新版 ETI v2）の描画をそのまま使い、固定のダミー回答（水×片手剣×フォンテーヌ。閲覧者の結果とは無関係）で生成。`node scripts/build-report-sample.js` で作り直し、同期の試験で差を検出。旧版のエニアグラム由来の欄（動機の深層・ウィング・成長／ストレス方向）は STYLE の欄に置き換わった。
- **国家の誤表示**：ニコ・スカーク・アーロイは、事実データで国家が未設定（意図的）なのに、表示の層が古い国家（ニコ＝ナタ 等）で埋めていた。運営者の判断で「国家なし」に統一。結果ページ・レポート・サンプル・マイページ（旧版の記録を含む）で外した。完全解析はもともと「—」。正本のエンジンと完全解析の生成器は変更していない。
