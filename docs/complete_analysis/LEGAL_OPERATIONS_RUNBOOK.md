## 1. 特商法の開示請求（個人事業者の氏名・所在地・電話番号）
公開ページの約束：「請求があった場合、遅滞なく開示します」。公開文面に、絶対的な期限（「24時間以内」など）は書かない。

- **内部の目標：請求を受けてから、原則1営業日以内に回答する。** 購入を判断する前に開示できることが、住所・電話番号・氏名を載せない方式の条件（消費者庁の説明では、「遅滞なく」は、申込みの前に十分な時間的余裕をもって提供すること）。
- 受付：メール（件名「特商法開示請求」）。X の DM で来た場合も、メールでの返信に切り替える。
- 回答する内容：**販売者の氏名（戸籍上の氏名）・現に活動している住所・確実に連絡できる電話番号。** 本人確認は求めない。拒否しない。
- 記録：受付の日時・返信の日時・相手のアドレスを記録する（個人情報なので、運営者の非公開の場所に保管。保管期間は、対応に必要な期間）。
- 期限を守れない期間（出張・休みなど）：公開ページの方式を見直す（氏名・所在地・電話番号を載せる）か、販売を止める。
- 年に1回、回答の定型文（住所・電話番号）が現在のものか確認する。
- 【公開前に原文で確認】消費者庁「特定商取引法ガイド」通信販売広告Q&A（氏名・住所・電話番号の省略の条件、屋号の扱い）、特商法第11条ただし書・第12条の6。

## 2. 個人情報の請求（開示・訂正・利用停止・削除など）
- **内部の目標：原則30日以内に対応する**（公開ページには、この日数を書かない。「遅滞なく」）。
- 本人確認：ログインに使っているメールアドレスからの連絡、またはログインに使っている X アカウントからの DM。購入された方は、決済の日時などを確認する。
- 手数料：原則無料。書面の郵送など、特別な実費が必要な場合は、**実施の前に本人へ説明**する。
- 法令・会計上、保持が必要な情報（注文・決済の記録。7年間）は、削除できない場合がある。その場合は、理由を知らせ、可能な範囲で対応する。
- アカウント削除：購入のある記録を持つ利用者は、DB の参照制約で、いまの手順では削除できない。**削除・匿名化の DB 関数は別タスクで設計・試験する**（法務ページの公開作業には混ぜない）。それまでは、個別に対応し、実施前に運営者が影響を確認する。

## 3. 購入トラブル
- 二重決済・正常に提供できない・契約内容との不一致・法令上必要な場合は、状況を確認して個別に対応する（Stripe の管理画面で状況を確認。返金すると、その購入のレポートは読めなくなる）。
- 提供開始後のお客様都合による返品・キャンセル・返金は、原則として受け付けない（規約・特商法・決済画面と同じ趣旨）。

## 4. 固有リンクの再発行（購入者への対応）
- **再発行は、漏えいなどの問題がある場合だけ行う。** リンクの紛失では、再発行しない（まず、Stripe から届いた請求書のメールを確認してもらう。見つからない場合は、購入の内容を確認のうえ、状況に応じて対応する）。
- 再発行すると、**以前のリンクは開けなくなり、そのリンクでマイページに登録していた閲覧も止まる**（complete_14）。請求書のメールのリンクも使えなくなる。
- 再発行したら、購入者へ、**新しいリンクと、以前のリンクが使えなくなったこと**を、メールで連絡する（メールは、購入者から連絡があった場合のアドレスにだけ送る。自前のメールサーバーは持たない）。
- 手順：`docs/complete_analysis/REPORT_LINKS_RUNBOOK.md`（SQL Editor での再発行）。悪用で停止した納品は、再発行しない（再発行すると有効に戻る）。

## 5. 購入のない一時的な記録の定期整理
- **内部の目標：月に1回。** 公開ページには、頻度を書かない（「不要になったものは、運営者が定期的に削除します」）。
- 手順：`docs/complete_analysis/OPERATIONS_RUNBOOK.md` の `complete_purge_result_links()`（SQL Editor。service_role は実行できない）。最後にリンクを開いた日から180日を過ぎた、購入のない結果が対象。
- 実行したら、日付と削除件数を記録する。
- 接続元の照合値（`result_link_rate`）は、新しいリンクの作成時と、この整理の時に、24時間を過ぎた行が消える。定期ジョブは無い。

## 6. サービス終了時の告知と PDF 保存の案内
- 公開ページの約束：「全部または一部を終了する場合、やむを得ない場合を除き、合理的な予告期間を設けて、本サイトその他適切な方法でお知らせする」。**固定の日数（30日前など）は約束しない。** 個別のメールによる通知は必須としない。サイト上のお知らせを基本とする。
- 終了を決めたら、順に：①販売を止める（`COMPLETE_SALES_OPEN` を外す。Webhook は有効のまま）②トップ・購入完了・レポートの各画面に、終了の予定日と「購入したレポートは PDF 等で端末に保存してください」を掲示する ③予告の期間の間は、購入済みのレポートを読めるようにする ④障害・外部サービスの停止・法令対応など、事前に告知できない場合は、分かり次第、掲示する。
- 「期限のない固有リンク」は、通常の有効期限がないという意味であり、サービスの永続を保証するものではない（公開ページにも、そう書いている）。
