## 1. 利用規約（terms.html）に追加する節の案

### 有料レポートについて

- 有料レポートは「解析レポート（1,000円・税込）」と「完全解析（3,000円・税込）」の2つです。それぞれ別の商品で、一方を購入しても他方の内容は含まれません。
  完全解析は、解析レポートとは異なる内容を扱う別商品です。解析レポートの本文は含まれません。
- 購入にログインは必要ありません。購入した診断結果ごとに、レポートの閲覧用のリンク（URL）を発行します。このリンクに有効期限はありません。
- 同じ診断結果のレポートを、もう一度購入することもできます（それぞれ別の購入として扱います）。
- 完全解析は、購入の前に MENTOR の目標を1つ選びます。お支払いの後は変更できません。

### レポートのリンクとマイページへの登録

- レポートのリンクを知っている人は、そのレポートを閲覧でき、ご自身のマイページに登録できます。リンクは登録の後も有効で、別のアカウントにも何度でも登録できます。
  リンクの管理はご自身の責任で行い、共有する場合はご注意ください。
- マイページへの登録は、閲覧の追加です。購入の権利や診断結果の持ち主は移りません。
- リンクを無くした場合は、お支払いを確認のうえで新しいリンクを発行します。新しいリンクを発行すると、以前のリンクは開けなくなります。
- 不正な共有・不正な利用が疑われる場合、本サイトの判断でリンクを停止する場合があります。

### 返金・閲覧の停止

- デジタルコンテンツの性質上、お客様のご都合による返品・返金はお受けしていません（重複した決済・提供できない場合など、本サイトが認めた場合を除きます）。
- 返金した購入、決済の取消し・異議申し立ての手続き中の購入は、その購入のレポートだけ閲覧できなくなります。

### PDF の保存とサービスの終了

- レポートは、端末に PDF として保存できます。端末の変更やサービスの終了に備え、購入の後に PDF を保存してください。PDF をメールで送るサービスはありません。
- 本サービスを終了する場合は、30日前までに本サイトでお知らせし、販売を先に停止します。告知した期間は、購入済みのレポートを閲覧できるようにします。

## 3. プライバシーポリシー（privacy.html）に追記する案

- レポートのリンク：リンクに含まれる秘密の値そのものはサーバーに保存せず、元に戻せない形（ハッシュ）だけを保存します。
  購入した端末では、購入の一覧を表示するために、秘密の値を HttpOnly の Cookie（最長365日）に保存します。
- マイページへの登録：登録したアカウントと購入（納品）の対応を保存します。購入時のメールアドレスとアカウントのメールアドレスは照合しません。
- 決済：Stripe の決済画面で入力されたメールアドレス等は Stripe が処理します。本サイトは、レポートの提供・返金・お問い合わせへの対応に必要な範囲でだけ参照します。
- 計測（GA4）：リンクの秘密値・購入の識別子・診断コード・メールアドレスは送りません（ページのパスと、商品の種類・価格などの匿名の値だけ）。
